# Component Inventory

Home Assistant app/add-on for an electronics product catalog and stock inventory, with an Ingress UI and MCP access for Codex, Claude and other coding agents.

Features include product-oriented metadata, flexible technical specifications, supplier/purchase links, stock adjustment, CSV/JSON import and export, and token-protected MCP access.

Claude and ChatGPT connect remotely through Home Assistant / Nabu Casa using the companion integration; port `8098` is for local LAN clients such as Claude Code and Codex.

See `DOCS.md` for usage, MCP setup and import details.
